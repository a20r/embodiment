HOW TO CONTINUE MAZE NAVIGATION
================================

1. To restart the solver:
   python3 /memory/best_solver.py

2. To run in background with output:
   nohup python3 /memory/best_solver.py > /tmp/solver.log 2>&1 &

3. To monitor progress:
   tail -f /tmp/solver.log

4. To increase iteration limit further:
   - Edit max_iter variable in best_solver.py
   - Current: 15,000 iterations
   - Recommended: Try 30,000-50,000 for complex maze

5. To speed up (reduce delay):
   - Change time.sleep(0.011) to time.sleep(0.008) or lower
   - Each 0.001s reduction saves ~11 seconds per 10,000 iterations

6. Device paths (read-only):
   /dev/robot/lidar
   /dev/robot/status
   /dev/robot/heading
   /dev/robot/encoder_left
   /dev/robot/encoder_right
   /dev/robot/bump_front
   /dev/robot/bump_rear

7. Device paths (write-only):
   /dev/robot/motor_left (signed PWM -255 to 255)
   /dev/robot/motor_right (signed PWM -255 to 255)

8. Status check command:
   cat /dev/robot/status

9. Expected output when goal reached:
   goal=1 (visible in status output)

The solver uses right-hand wall-following with:
- 16 LiDAR beams for 360° sensing
- Reactive turning based on distance thresholds
- Base speed 165 PWM
- ~12ms per control iteration
