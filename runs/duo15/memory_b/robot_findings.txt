# Robot Control System Findings

## Confirmed Device Ports:
- d0: Unknown state (0 initially)
- d1: Possibly movement/speed control (changes d6, d9)
- d2: Sensor data (16 values, possibly LIDAR/distance array)
- d3: Status string: tick=X goal=Y here=Z (tick increments each read, goal and here are 0)
- d4: Bearing/heading in degrees (floats like 180-190)
- d5: 0 (unknown)
- d6: Changes with d1 write (was 0, became -1)
- d7: Unknown (not tested yet)
- d8: Transmit to other robot (write-only)
- d9: Changes with d1 write (was 0, became 4)
- d10: Receive from other robot (read-only, no messages yet)
- d11: Constant ~0.5

## Observations:
- goal=0, here=0 in status means we haven't reached goal yet
- Bearing changes slowly (180-190 degrees)
- Sensor data shows distance-like values (many < 1.0)
- Other robot hasn't responded yet to HELLO
