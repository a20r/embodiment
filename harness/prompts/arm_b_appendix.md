
Your `/memory` is organized under a prescribed system. Follow it:

- `/memory/INDEX.md` — the table of contents. One line per file:
  path, one-sentence purpose. Read it first every episode; update it
  whenever you add or remove a file.
- `/memory/topics/<topic>.md` — one file per subject (e.g. the robot's
  hardware, the maze, control strategies). Facts go in the most specific
  topic file, stated so they are checkable later; note how you learned
  each fact.
- `/memory/CHANGELOG.md` — append one dated line per episode
  summarizing what changed and why.
- `/memory/conventions.md` — the rules of this system. Read it before
  writing anything; keep it updated if you refine the conventions.
