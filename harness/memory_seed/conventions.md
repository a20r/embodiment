# Memory conventions

1. INDEX.md lists every file with a one-sentence purpose. Update it in
   the same episode you add or remove a file.
2. Facts live in the most specific `topics/` file. State each fact so a
   stranger could check it (numbers, device paths, exact commands), and
   note how you learned it.
3. Prefer editing a fact in place over appending contradictions. If you
   overturn a belief, say what replaced it and why.
4. CHANGELOG.md gets exactly one appended line per episode:
   `[episode N] <what changed> — <why>`.
5. Before acting each episode: read INDEX.md, then the topics you need.
   Before the episode ends: write what your future self will wish you
   had written.
